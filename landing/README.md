# Velocity Showcase Website

The public landing page and showcase website for Velocity, deployed on Vercel.

## Tech Stack

- React 19 + TypeScript
- Vite 6
- Tailwind CSS
- Satoshi & JetBrains Mono typography
- Lucide React icons

## Local Development

```bash
cd landing
npm install
npm run dev
```

## Build

```bash
npm run build
```
