# Velocity v0.1.0

Velocity is a sovereign personal AI assistant and technical thought partner engineered for deep cognitive leverage, persistent memory, and borderless minimalist execution.

This release marks the completion of the core cloud infrastructure, the Hindsight memory engine, the flat monochrome web client, and the disaster recovery pipeline.

---

## Key Highlights

### 1. Memory & Cognition Engine
- **Deterministic Recall -> Execution -> Retain Loop**: Every conversation turn queries standing memory, executes with real-time reasoning, and asynchronously retains new observations into Hindsight.
- **Foundational Mental Models**: Structured background synthesis across four core dimensions:
  - `current-context`: Active focus, open loops, recent decisions, and immediate objectives.
  - `user-persona`: Communication preferences, engineering beliefs, and technical taste.
  - `projects-and-decisions`: Architecture choices, tech stack, and decision rationale.
  - `goals-and-interests`: Long-term directions and research topics.
- **Dynamic Cognitive Tools**: Transparent model tool-calling via `tavily_search`, `consult_memory`, and `read_mental_model`.
- **Private Personalized System Prompt**: System prompts are isolated in gitignored configuration files (`config/system_prompt.json`) to protect personal preferences from repository leaks.

### 2. Flat Monochrome Web Client
- **Borderless Surface Architecture**: Visual hierarchy established strictly through surface color contrast (`--bg-primary`, `--bg-card`, `--bg-modal-inner`) without borders or outlines.
- **Satoshi Medium Typography**: Strict typographic restraint using Satoshi Medium (`w500`) and SemiBold (`w600`).
- **Centered Hero to Docked Transition**: Empty chats feature a centered greeting and input capsule that animates into a docked bottom capsule upon conversation start.
- **Single-Line Cognitive Status Indicator**: Subtle flowing text shimmer indicator during thinking and tool execution that vanishes the moment response tokens stream.
- **Per-Session Cognitive Controls**: Popover anchored to the input capsule for adjusting Thinking Effort (`none` to `max`), Recall Budget (`low`, `medium`, `high`), and Verbosity (`low`, `medium`, `high`).
- **In-App Memory Inspector**: Direct modal view of synthesized mental models without intermediary tabs or unnecessary controls.
- **Split Sidebar Footer**: Minimal status dot with pure-typography health diagnostics on the left; Memory Inspector and Dark/Light theme toggles on the right.
- **Smart Scroll Lock Pill**: Minimal circular arrow button that floats into view when scrolled up greater than 120 pixels.
- **Terminal Prompt Brand Mark**: Standalone `>` mark used as the web favicon and mobile app icon.

### 3. Hardened Production Infrastructure
- **Optimized for 2 GB VPS**: Runs on a 2 GB RAM Linode instance backed by a 4 GB NVMe swap partition (`vm.swappiness=10`) to eliminate out-of-memory risks.
- **Dual-Layer Firewall**: Ubuntu UFW blocks all public incoming traffic except SSH (port 22); Docker port bindings are strictly pinned to `127.0.0.1`.
- **Cloudflare Tunnel**: Zero open web ports on the VPS. Traffic routes securely to your custom domain over outbound connections.
- **Cloudflare Zero Trust Authentication**: Web interface is protected at Cloudflare's edge using email One-Time PIN identity verification.
- **Hindsight Control Plane**: Accessible at your memory subdomain behind the same Zero Trust authentication layer.

### 4. Disaster Recovery & Automated Backups
- **Nightly Automated Snapshots**: Complete automated dumps of PostgreSQL (Hindsight vectors and mental models), SQLite (chats and sessions), and configuration.
- **Cloudflare R2 Off-Site Sync**: Direct off-site sync to Cloudflare R2 bucket (`velocity-backups`) with automated 14-day rotation.
- **Single-Command Recovery**: Dedicated restore script (`scripts/restore.sh`) capable of restoring the entire state from an archive in under 10 seconds.

### 5. Mobile Client Companion Spec
- **Mobile Integration Specification**: `MOBILE_SPEC.md` provides full Flutter design tokens, layout blueprints, and Server-Sent Events (SSE) streaming contracts.
- **One-Second QR Pairing**: Dedicated `/mobile` route displays a dark-mode pairing QR code encoding Cloudflare Service Token credentials for instant mobile onboarding.


```json
{"status":"ok","backend":"healthy","hindsight":"healthy","database":"healthy"}
```
