# Topics & Intellectual Curiosities

This directory contains dossiers and notes on persistent intellectual curiosities, domains of inquiry, and personal interests.

## Structure
- Each topic is represented by a markdown document (e.g. `neuroscience.md`, `philosophy.md`, `physiology.md`, `automotive.md`).
- When a topic grows beyond ~1,500 words or develops distinct sub-disciplines, it is promoted to a subfolder with an `index.md`.
- Topic documents capture core mental models, key frameworks, and Sathwik's perspectives.
