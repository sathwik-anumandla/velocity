# Tech Stack & Infrastructure

## Primary Languages & Frameworks
- Python (FastAPI, SQLite, Asyncio)
- TypeScript / React (Vite, Tailwind CSS, Lucide React)
- Flutter / Dart (Mobile client)

## Infrastructure & Runtime
- Host: Linode VPS (Ubuntu / Debian, Docker Compose)
- Databases: SQLite with WAL mode, PostgreSQL with pgvector (for Hindsight)
- Memory System: Deterministic Markdown Vault + Hindsight episodic engine
- LLM Provider: OpenAI Responses API / Chat API (models: gpt-5.4, gpt-5.4-mini)
