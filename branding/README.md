# Velocity — Brand Identity

## Wordmark

Use the full **Velocity** wordmark in Satoshi Bold (700). SVG lettering is outlined
from the bundled font, so rendering does not depend on locally installed fonts.
Do not substitute a standalone V, shooting stars, or the old angle-bracket mark.

## Palette

Keep surfaces black, white, and neutral gray. The only chromatic accent is
**#54E6D4**; use **#087F73** for legible accent text on light backgrounds.
In-app lettering stays crisp. Launcher icons have a subtle teal glow localized
to the initial letter, on black; do not add a full-word neon halo.

## Assets

- `velocity_logo.svg`: outlined Satoshi Bold wordmark.
- `velocity_app_icon.svg`: scalable full-word icon and localized glow.
- `../web/public/favicon.svg`: matching browser icon.
- Android adaptive foreground: `ic_launcher_foreground.xml`; Android 13 themed
  icons use the monochrome full-word outline without a glow.

Legacy concept images and `velocity_mark.svg` are archival, not active branding.
