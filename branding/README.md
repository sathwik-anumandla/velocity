# Velocity — Brand Identity

## The Mark: `>` (The Angle Bracket / Terminal Prompt)

Velocity's brand mark is the **`>`** (angle bracket).

```
   \
    \
    /
   /
```

### Core Symbolism
1. **The Pure Vector ($\vec{v}$)**: Velocity is speed with direction. The angle bracket removes the shaft of an arrow, leaving only pure forward kinetic direction.
2. **Terminal Heritage**: Directly references the prompt symbol (`>_`), embodying developer-first craftsmanship, instant responsiveness, and intelligence awaiting execution.
3. **Radical Minimalism**: Zero ornamentation, zero borders, zero artificial gradients. It is pure typography and geometry that pairs with Satoshi Medium.
